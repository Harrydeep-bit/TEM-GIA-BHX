# In Tem Giá (Android)

App Android in tem giá (tem thường 75×40, tem khuyến mãi 75×50, tem nẹp 190×75) thẳng ra máy in nhiệt qua wifi (cổng 9100, lệnh ESC/POS).

## Lấy file APK
Mỗi lần đẩy code lên nhánh `main`, GitHub Actions tự build. Vào mục **Releases** của repo, tải `InTemGia.apk` về điện thoại rồi cài.

## Sửa giao diện
Toàn bộ trang in tem nằm trong `app/src/main/assets/index.html`.
